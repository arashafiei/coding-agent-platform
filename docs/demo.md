# Suggested 15-minute demo
1. Start stack with Docker Compose.
2. Show n8n planning/execution workflows.
3. Create a project from Dashboard.
4. Watch Planner event, inspect plan, add manager feedback and approve.
5. Watch Coder -> Runner -> Reviewer; intentionally choose a prompt likely to require a fix if you want to demonstrate Fixer.
6. Open generated project under `storage/projects` and show Git history.
7. Show logs in `logs/system/events.log` and final run status.
